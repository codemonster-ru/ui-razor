# Contributing

For changes to component markup or behavior, discuss the shared contract in
[CodeMonster UI](https://github.com/codemonster-ru/ui). Include the Razor package version and a reproducible example.
Follow the [CodeMonster commit style](https://github.com/codemonster-ru/.github/blob/main/COMMIT_STYLE.md).

Report suspected vulnerabilities through the [security policy](./SECURITY.md).
